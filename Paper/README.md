# Paper Preparation Notes

This folder contains the literature papers supplied for the project and two
project-specific writing guides:

1. [Literature comparison and research positioning](01_literature_comparison_and_positioning.md)
2. [Complete project explanation in layman terms](02_complete_project_in_layman_terms.md)

The comparison document distinguishes three kinds of evidence:

- **Direct comparison:** methods evaluated on the same model, images, attacks,
  and split.
- **Cross-paper context:** results reported by different papers under different
  datasets and protocols.
- **Proposed contribution:** what is technically different about the present
  work, independent of whether one percentage is numerically smaller.

This distinction is essential. A paper should not claim that one method
outperforms another merely because its ASR is lower on a different dataset or
attack.
